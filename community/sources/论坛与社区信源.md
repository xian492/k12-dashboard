# 全国 K12 论坛与社区信源入口

> 调研日期：2026-10-22。本文记录官方信源之外，可用于发现全国 K12 入学、升学和学校动态的公开论坛、家长社区、地方生活论坛及内容平台。社区内容仅作线索，涉及政策、招生资格、名额、时间和学校行为时，仍需回查当地教育部门、考试院或学校原始公告。看板中应将社区线索与官方省、市、区县和学校信源分开；只使用无需登录即可访问的公开页面，不绕过付费、会员、登录、验证码或访问限制。

## 一、社区信源类型

| 类型 | 代表来源 | 适合发现 | 主要局限 |
|---|---|---|---|
| 垂直升学网站 | 家长帮、北京小升初网、千帆育儿 | 招生节点、政策解读、择校经验和家长问答 | 转载、机构文章和课程推广较多 |
| 地方生活论坛 | 19 楼、得意生活、回龙观社区网、江阴论坛 | 本地学校、家长会、校区建设和区域变化 | 教育内容与房产、生活服务混杂 |
| 单校或城市贴吧 | 百度贴吧及学校吧 | 报到、住宿、分班、校园生活和即时问答 | 碎片化、匿名性强、广告和传闻较多 |
| 问答与经验社区 | 知乎、学鹿、伴苗 | 长期经验、问题解释和学校比较 | 时效、地域和作者身份不稳定 |
| 内容平台 | 微信公众号、小红书、抖音、视频号 | 早期线索、家长经历和现场信息 | 登录限制、推荐流和商业内容影响归档 |
| 半封闭社群 | 知识星球、QQ群、微信群 | 更早的报名提醒、经验交换和即时答疑 | 无法稳定公开归档，不适合默认自动采集 |

这些来源承担的角色不同：垂直网站适合持续搜索，地方论坛适合发现区域变化，贴吧和内容平台适合捕捉即时反馈，半封闭社群只适合在合法访问范围内人工参考。它们都不能替代教育部门、考试院或学校的原始公告。

### 全国平台的地域识别

全国性论坛必须先做地域识别，再进入地方栏目：

1. 页面所属城市频道或板块；
2. 标题、正文中的省、市、区县名；
3. 学校名称与学校地域词典；
4. 作者定位只能作为弱线索，不能单独决定地域。

同名学校较多，例如“实验中学”“第一中学”“育才中学”，没有城市或区县佐证时不得自动归类。

## 四、不同信源适合发现什么

| 信息类型 | 更适合关注的来源 | 使用方式 |
|---|---|---|
| 报名、摇号、派位、转学和学位申请 | 家长帮、城市垂直网站、地方教育论坛 | 只作为政策线索，必须回查官方公告 |
| 报到、住宿、校服、分班和校园安排 | 学校贴吧、地方论坛、家长社区 | 保留原始帖子和发布时间，不把个体经验写成普遍结论 |
| 学校口碑、作业量和家长体验 | 知乎、地方论坛、家长帮、篱笆等经验社区 | 多个来源交叉阅读，标记主观判断和利益关系 |
| 新校区、学区变化和周边建设 | 本地生活论坛、地方媒体互动区、社区帖子 | 关注多个家庭或多个帖子是否指向同一变化，再查政府或学校信息 |
| 争议、爆料和传闻 | 贴吧、内容平台、半封闭社群 | 只当作发现线索，不直接生成确定性摘要 |

社区来源的价值通常不在于直接提供“正确答案”，而在于提前暴露官方页面尚未覆盖的问题、家长实际遇到的流程和某个区域正在发生的变化。它的弱点也正是信息来自个体经验、匿名发言或商业运营，因此应保留来源上下文，避免只截取结论。

## 五、内容平台与半封闭社群

知识星球、公众号、QQ群和微信群能提供更早的线索，但公开搜索通常无法完整确认内容范围，也难以稳定归档。

可在知识星球 App 内按地域搜索：`城市名 + 小升初`、`城市名 + 中考`、`区县名 + 升学`、`学校名`。本地 RSSHub 已有知识星球路由：

```text
/zsxq/group/:id/:scope?
```

可用范围包括 `all`、`digests`、`by_owner`、`questions`、`tasks`。如果使用，只读取账号合法加入的星球，并优先选择 `by_owner` 或 `digests`。它需要账号自己的 `ZSXQ_ACCESS_TOKEN`；令牌必须保存在本地环境变量中，不得提交到仓库、写入 OPML 或放进页面。

微信公众号可在具备合法订阅能力后作为独立来源。微信群和 QQ 群只适合人工确认，不自动抓取，不公开转发群内消息。

小红书、抖音和视频号覆盖全国大量家长内容，但登录限制、推荐流、短视频解析和商业软文使其更适合作为人工发现渠道，不适合现阶段的自动看板。

### 全国地域字段

每条社区线索至少保存：

```text
省级行政区、城市、区县、学校、学段、事件类型、来源类型、原始发布时间、发现时间、官方核验链接
```

跨地区通用内容应放在“全国”栏目，不复制到每个城市。学校名录、招生资格名单等汇总信息应放到对应省、市或区县栏目，不归入某一所具体学校。
