# 全国 K12 论坛与社区信源入口

> 调研日期：2026-10-22。本文记录官方信源之外、可用于发现全国 K12 入学、升学和学校动态的公开入口。论坛、家长投稿、垂直网站和社交平台均不是权威信源；涉及政策、招生资格、名额、时间和学校行为的内容，必须回查当地教育部门、考试院或学校原始公告。

## 一、使用原则

- 看板中单独设置“社区线索”或“第三方资讯”，不得与官方省、市、区县和学校信源混排。
- 每条内容必须携带省、市、区县和学校标签；无法判断地域的内容不自动进入地方栏目。
- 只采集无需登录即可访问的公开页面，不绕过付费、会员、登录、验证码或访问限制。
- 自动展示时只保留标题、日期、来源、链接和短摘要，不复制全文。
- 社区内容默认标为“未核实”；找到教育部门、考试院或学校原文后，才可改为“已核实”。
- 优先收录政策变化、报名节点、开放日、新建学校、转学、划片、派位、中考招生和家长实操反馈；排除培训广告、试卷售卖、课程销售、房产营销和泛育儿内容。

### 全国平台的地域识别

全国性论坛必须先做地域识别，再进入候选列表。建议按以下顺序判断：

1. 页面所属城市频道或板块；
2. 标题、正文中的省、市、区县名；
3. 学校名称与学校地域词典；
4. 作者定位只能作为弱线索，不能单独决定地域。

同名学校较多，例如“实验中学”“第一中学”“育才中学”，没有城市或区县佐证时不得自动归类。

## 五、知识星球与半封闭社群

知识星球、公众号、QQ群和微信群能提供更早的线索，但公开搜索通常无法确认活跃度，也难以稳定归档。

可在知识星球 App 内按地域搜索：`城市名 + 小升初`、`城市名 + 中考`、`区县名 + 升学`、`学校名`。本地 RSSHub 已有知识星球路由：

```text
/zsxq/group/:id/:scope?
```

可用范围包括 `all`、`digests`、`by_owner`、`questions`、`tasks`。如后续接入，建议只使用 `by_owner` 或 `digests`。它需要账号自己的 `ZSXQ_ACCESS_TOKEN`，且只能访问该账号合法加入的星球；令牌必须保存在本地环境变量中，不得提交到仓库、写入 OPML 或放进页面。

微信公众号可在具备合法订阅能力后作为独立来源。微信群和 QQ 群只适合人工确认，不自动抓取，不公开转发群内消息。

小红书、抖音和视频号覆盖全国大量家长内容，但登录限制、推荐流、短视频解析和商业软文使其不适合现阶段的自动看板；可作为人工发现渠道。

## 六、全国筛选规则

### 推荐保留

```text
幼升小、小升初、中考、中招、招生、报名、志愿、派位、摇号、登记入学、划片、学区、转学、跨区、随迁子女、积分入学、开放日、校园日、录取、分班、指标生、名额分配、集团校、新校区、招生计划、入学材料、信息采集、学位申请、对口学校
```

除通用词外，至少还应命中以下任意一项，才能自动进入地方候选列表：

- 省、市、区县名；
- 已配置学校名或教育集团名；
- 城市频道、城市论坛板块或明确的地域标签。

### 默认排除

```text
试卷、答案、资料领取、课程、培训、补课、家教、机构、优惠、团购、免费资料、微信群、进群、房价、卖房、租房、装修、征婚、招聘、母婴用品、健康问诊、早教产品、托管招生、留学中介、志愿填报收费
```

以下措辞不一定删除，但必须标为“待核实”，且不得自动生成确定性摘要：

```text
网传、据说、内部消息、家长反馈、疑似、可能、预测、排名、梯队、避雷、上岸、点招、密电、DZ、MD、择校线、内幕、承诺录取
```

### 全国地域字段

建议每条社区线索至少保存：

```text
省级行政区、城市、区县、学校、学段、事件类型、来源类型、可信状态、原始发布时间、发现时间、官方核验链接
```

跨地区通用内容应放在“全国”栏目，不复制到每个城市。学校名录、招生资格名单等汇总信息应放到对应省、市或区县栏目，不归入某一所具体学校。

## 七、建议的接入顺序

1. **城市垂直论坛试点**：北京小升初网、上海千帆、广州妈妈网、深圳家在深圳、成都壹牛、武汉得意生活、杭州 19 楼各选一个公开列表。
2. **统一地域识别**：建立省、市、区县和学校别名词典，先判断地域再做内容分类。
3. **统一内容过滤**：应用保留词、排除词和不确定性词；商业内容默认不展示。
4. **官方回查**：从社区文章中提取教育部门、考试院或学校链接；有官方原文时只展示官方版本，并把社区帖作为线索来源。
5. **全国平台补充**：家长帮、知乎和百度贴吧只做跨城市缺口补充，不作为主要抓取源。
6. **本地论坛扩展**：按“待继续扩展的城市”逐个验证活跃度、公开访问和分页稳定性。
7. **半封闭渠道最后接入**：只在用户拥有合法访问权且明确提供目标时配置知识星球或公众号，不接入私密群聊。

论坛信息进入看板时，统一使用 `社区线索`、`未核实/已核实`、`省市区`、`学段`、`内容类型`、`原始发布时间` 标签。这样可以扩大到全国，又不会让地方传闻与官方公告混淆。
