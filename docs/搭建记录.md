# K12 官方信源看板 · 当前说明

在线地址：https://xian492.github.io/k12-dashboard/

当前版本已于 2026-10-22 完成线上核验。

## 看板用途

本项目用于集中查看北京 K12 官方公开信息，包括市级教育通知、各区义务教育入学政策、区级教育动态、学校动态，以及学校官网和微信公众号入口。

看板由 GitHub Actions 自动构建，通过 GitHub Pages 发布，不依赖独立服务器。

## 当前数据覆盖

| 层级 | 当前内容 |
|---|---|
| 市级 | 北京市教委通知公告、教育部公告公示、全市学校名单等学校信息 |
| 区级 | 北京 18 个区的义务教育入学政策，以及可稳定访问的区政府、区教委教育动态 |
| 区级学校信息 | 西城、石景山、门头沟、房山、通州、大兴、怀柔、密云、经开区共 10 条学校名录或综合信息 |
| 学校入口与动态 | 18 个区共 149 个学校入口，每区至少 3 所；有可靠信源的学校同时展示动态 |
| 学校官网 | 其中 114 条参考太星网络“北京小升初 · 关注网站”页面，覆盖海淀、朝阳、西城、东城、丰台、昌平、大兴、顺义、通州和石景山 |
| 微信公众号 | 99 所学校对应 101 个公众号 ID；17 个区设置区级教育公众号入口 |

每个区至少保留 3 所学校。点击学校名称可进入学校官网；没有稳定独立站时进入所属区政府、教委或官方学校目录。学校有可靠官方动态时展示具体内容，没有动态时仅保留导航入口，不生成占位信息。

市级栏目名称可进入北京市教委或教育部官网，分区台账中的 18 个区名可进入对应区政府、教委或经开区官方站。

学校官网和微信公众号 ID 只用于人工导航，不作为自动抓取源，也不会写入聚合 RSS。太星页面中被站内相对路径包裹的学校链接已还原为直接网址，重复学校合并，明显名称错误已规范化。

## 数据筛选原则

看板按信息的实际发布范围归类：

- 全市学校名单、全市招生资格名单放在“全市学校信息”。
- 区级学校名录、区级招生资格、学校地址及联系电话放在对应区的“区级学校信息”。
- 只有标题或正文明确指向一所学校的内容，才进入该校的“学校动态”。
- 通用名单不会重复出现在具体学校下面。

以下内容会自动排除：

- 部门预算、部门决算、财务审计、政府采购、招标和比选等行政财务信息
- 网站版权、ICP备案、公安备案和 `javascript:` 链接
- 首页、栏目入口、学校简介、联系我们等导航链接
- “动态待接入”“暂无有效动态”等无实际内容的占位条目

学校官网不可用或页面无法稳定解析时，可以使用明确提及该学校的区政府、区教委公开信息作为补充；通用名单和名录只在市级或区级栏展示，不会归入学校动态。

## 更新与发布

GitHub Actions 每 6 小时运行一次：

1. 执行 `python3 tools/build.py` 拉取并解析官方信源。
2. 生成 `docs/index.html`、聚合订阅 `docs/feed.xml` 和本次构建使用的 `docs/data.json`。
3. 将 `docs/` 作为 GitHub Pages 构建产物发布。

定时任务按北京时间约在 02:00、08:00、14:00 和 20:00 运行，也可以在 GitHub Actions 中手动触发 `Build dashboard`。

`docs/data.json` 是本地构建缓存，用于比较前后两次抓取结果。该文件已在 `.gitignore` 中忽略，不提交到仓库；GitHub Pages 发布的是工作流现场生成的 `docs/` 页面产物。

## 本地运行

项目只使用 Python 标准库，无需安装额外依赖：

```bash
python3 tools/build.py
```

构建完成后直接打开 `docs/index.html` 查看结果。

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

## 主要文件

| 路径 | 用途 |
|---|---|
| `tools/build.py` | 信源配置、学校与公众号目录、抓取解析、内容过滤和页面生成 |
| `tests/test_build.py` | 学校动态分配、目录完整性、RSS 隔离、无效链接过滤和页面结构测试 |
| `.github/workflows/build.yml` | 定时构建和 GitHub Pages 发布 |
| `docs/index.html` | 当前发布页面 |
| `docs/feed.xml` | 区教委、学校动态及学校综合信息的聚合 RSS |
| `docs/data.json` | 构建时生成的本地数据快照，不纳入版本控制 |

## 当前限制

- 太星目录中的部分学校网站仍使用 HTTP、旧版路径或历史域名，入口按来源页面收录，不代表已逐站验证当前可访问性。
- 部分学校官网采用动态渲染或访问限制，暂时无法可靠抓取；这类学校只保留官网或官方目录入口。
- 没有真实学校动态的学校会保留在学校入口目录中，但不展示替代性通用信息。
- 区级学校名录等综合信息只在找到可靠官方页面的区展示，不使用非官方内容补齐。
- 官网结构调整后，对应解析规则可能需要更新。
- 看板只聚合公开官方信源，不采集需要登录的内容，也不把公众号非公开接口作为默认数据来源。
