## 一、看板是什么

20+ 路北京官方信源的最新条目，按区组织的网页台账。GitHub Actions 每 6 小时自动拉取更新，GitHub Pages 托管，零服务器。

## 二、架构

官方信源不需要 RSSHub 中转：yjrx 是干净的 JSON 接口，市教委和教育部是可解析的静态 HTML，Actions 直接拉原始接口即可。

```
每 6 小时（北京 02/08/14/20 点）GitHub Actions 跑 tools/build.py
  ├─ yjrx 18 区招生政策 JSON
  ├─ 市教委通知公告页、教育部公告页（HTML 解析）
  └─ 4 所学校官网（HTML 解析）
  → 生成 docs/index.html + data.json 快照
  → 部署 Pages，快照提交回仓库（政策变化可 git 回溯）
```

构建脚本纯 Python 标准库，Actions 零安装直接跑。私有仓库的 Pages 只有协作者可见。

## 三、信源接入

**区级 18 路**：各区教委没有独立官网，权威发布点是市义务教育入学平台（yjrx.bjedu.cn）各区专区。政策列表是 JS 动态加载，但数据源是干净的 JSON：`/uploads/json/{fid}.json`，fid 从各区 `portal_{区缩写}/zszc.html` 源码的 `initPaginator()` 参数取。

**市级 2 路**：市教委页面有 http→https 重定向，通知链接格式 `./202610/t20261021_xxx.html`，正则按 `\d{6}/t\d{8}_\d+` 匹配。写正则前先打印页面原始片段核对，不要猜。

**校级 4 路**：人大附中（通知公告+招生资讯）、清华附中（招生专栏）、北师大附中（招生专栏）、首师大附中（校园快讯）。试过的其余学校：101/八中是动态渲染，十一学校 403，汇文/五中/陈经纶/八十中/丰台十二中/潞河等无独立官网。**官网路线天花板就是这 4 所**，学校信息主场在公众号，补齐要靠 wewe-rss 通道。

## 四、页面设计

政务台账风格：宋体标题（对应红头文件）、朱砂红只做语义色（NEW 徽章/今天标记/题线）、纸白底。第一屏是招生季时间轴（市政策 4 月中→区细则 4 月底→信息采集 5 月→派位 6 月→录取 7 月），标出当前处于空窗期——这个工具的本质是强周期：平时静默，4-7 月爆发。

18 个区一行一区（区名、条数、最新政策、学校数、NEW），点击展开看全量。

## 五、维护

| 事项 | 方法 |
|---|---|
| 某区返回空 | 平台改版换 fid：重抓 `portal_{区}/zszc.html` 源码 initPaginator 参数，改 build.py 的 DISTRICTS 表 |
| 市级解析失效 | 页面改版，先打印原始 HTML 核对结构再改正则 |
| 加学校 | SCHOOLS 表加条目 + PARSERS 加对应解析器（四种模板：rdfz/qhfz/sdfz/cnuhs） |
| 加公众号信源 | 部署 wewe-rss 后接入 |
| 手动构建 | `gh workflow run build.yml` |
