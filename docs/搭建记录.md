# K12 官方信源看板 · 当前说明

在线地址：https://xian492.github.io/k12-dashboard/

## 看板用途

本项目用于集中查看北京 K12 官方公开信息，包括市级教育通知、各区义务教育入学政策、区级教育动态和代表性学校动态。

看板由 GitHub Actions 自动构建，通过 GitHub Pages 发布，不依赖独立服务器。

## 当前数据覆盖

- 北京市教委通知公告
- 教育部公告公示
- 全市学校名单等市级学校信息
- 北京 18 个区的义务教育入学政策
- 可稳定访问的区政府、区教委教育动态
- 各区学校名录、招生资格等区级学校信息
- 18 个区共 62 所代表性学校

每个区至少保留 3 所学校。学校有可靠官方动态时展示具体内容；暂时没有稳定有效信源时，仅显示“暂无有效动态”，不使用通用名单或占位链接填充。

## 数据筛选原则

看板按信息的实际发布范围归类：全市学校名单放在市级栏，区级学校名录和招生资格信息放在对应区的区级栏，只有明确指向一所学校的内容才进入该校动态。

以下内容会自动排除：

- 部门预算、部门决算、财务审计、政府采购、招标和比选等行政财务信息
- 网站版权、ICP备案、公安备案和 `javascript:` 链接
- 首页、栏目入口、学校简介、联系我们等导航链接
- “动态待接入”等无实际内容的占位链接

学校官网不可用或页面无法稳定解析时，可以使用明确提及该学校的区政府、区教委公开信息作为补充；通用名单和名录只在市级或区级栏展示，不会归入学校动态。

## 更新与发布

GitHub Actions 每 6 小时运行一次：

1. 执行 `python3 tools/build.py` 拉取并解析官方信源。
2. 生成 `docs/index.html` 和本次构建使用的 `docs/data.json`。
3. 将 `docs/` 作为 GitHub Pages 构建产物发布。

定时任务按北京时间约在 02:00、08:00、14:00 和 20:00 运行，也可以在 GitHub Actions 中手动触发 `Build dashboard`。

`docs/data.json` 是本地和构建过程中的数据快照，已在 `.gitignore` 中忽略；仓库长期维护的页面产物是 `docs/index.html`。

## 本地运行

项目只使用 Python 标准库，无需安装额外依赖：

```bash
python3 tools/build.py
```

构建完成后直接打开 `docs/index.html` 查看结果。

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

## 主要文件

| 路径 | 用途 |
|---|---|
| `tools/build.py` | 信源配置、抓取解析、内容过滤和页面生成 |
| `tests/test_build.py` | 学校动态分配、无效链接过滤和页面结构测试 |
| `.github/workflows/build.yml` | 定时构建和 GitHub Pages 发布 |
| `docs/index.html` | 当前发布页面 |
| `docs/data.json` | 构建时生成的本地数据快照，不纳入版本控制 |

## 当前限制

- 部分学校没有稳定官网，或官网采用动态渲染、访问限制等方式，暂时无法可靠抓取。
- 没有真实学校动态的学校会保留在区级学校目录中，但不展示替代性通用链接。
- 官网结构调整后，对应解析规则可能需要更新。
- 看板只聚合公开官方信源，不采集需要登录的内容，也不把公众号非公开接口作为默认数据来源。
